# Конвертер EFKI

Программа для автоматической конвертации данных о должниках из выгрузок Excel в формат XML (версия 4.1), 
соответствующий требованиям GUTDF. Утилита формирует готовые файлы для передачи 
в четыре Бюро Кредитных Историй (БКИ): ОКБ, Скоринг, КБРС и НБКИ. 
Выгрузка Excel является самописной и не имеет какого-либо стандарта, 
в своём проекте вы можете изменить код для [парсинга](excel_parser.py) или сделать нужную версию файла. 
Проект был создан для ПКО, поэтому может не подойти другим организациям, может являться для них лишь примером.

## Особенности и возможности

* Графический интерфейс для удобной работы пользователей и интерфейс командной строки для автоматизации.
* Поддержка как современных файлов `.xlsx`, так и устаревших `.xls` (автоматическая конвертация во временный формат).
* Выборочная генерация файлов: возможность формировать XML только для нужных БКИ и сохранять их в указанную директорию.
* Автоматическое определение типа события на основе статуса долга:
    * `2.11.2` (добавление) — для статусов, начинающихся с `add`.
    * `2.3` (изменение данных) — для статусов, начинающихся с `edit`. 
    * `2.5` (закрытие) — для статусов, начинающихся с `close`.
* Встроенный набор автотестов для проверки форматирования дат, сумм, очистки текста и структуры XML.

## Требования и установка

Для работы приложения требуется Python 3 и установленные зависимости. Тесты проводились для Python 3.13.12. 

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Eklipti/inbg-conventor-xml-for-bki.git
cd inbg-conventor-xml-for-bki
```

2. Установите необходимые библиотеки (рекомендуется использовать виртуальное окружение):

```bash
pip install -r requirements.txt
```

Для корректной работы утилиты необходим файл `config.json`. Его структуру можно найти по пути [tests\example\example.json](tests\example\example.json).

## Использование

### Запуск через графический интерфейс (GUI)

Просто запустите главный файл без аргументов:

```bash
python main.py
```

В открывшемся окне выберите исходный Excel-файл, конфигурационный JSON, 
папку для сохранения результатов и отметьте галочками нужные БКИ. После этого нажмите кнопку "КОНВЕРТАЦИЯ".

### Запуск через командную строку (CLI)

Используйте аргументы командной строки:

```bash
python main.py -i <путь_к_файлу.xlsx> [-j config.json] [-o <папка>] [--bki okb scoring kbrs nbki] [-v] [-d]
```

* `-i` / `--input` *(обязательный)* — путь к Excel-файлу `.xls` или `.xlsx`.

* `-j` / `--json` — путь к конфигурации (по умолчанию `config.json`).
* `-v` / `--verbose` — включить подробный вывод логов в консоль.
* `-d` / `--debug` — режим отладки (используется фиксированный номер запуска 1111, файл `config.json` не перезаписывается).
* `-o`, `--output` — путь к директории для сохранения файлов (по умолчанию используется текущая директория).
* `--bki` — список БКИ для генерации файлов через пробел (доступно: `okb`, `scoring`, `kbrs`, `nbki`). 
> Примечание: Если указать флаг без значений (`--bki`), процесс пройдет без сохранения файлов.

## Требования к входному Excel-файлу

Чтобы парсер корректно считал данные, файл должен соответствовать строгим правилам:

1. **Лист данных**: Информация должна находиться на листе с названием `Активные`.
2. **Шапка таблицы**: Вторая строка листа (`row 2`) должна содержать заголовки.
3. **Ключевой столбец**: Обязательно наличие столбца с заголовком `# в33` (используется как ID записи).
4. **Колонки**: Требуется наличие стандартных столбцов (Фамилия, Имя, Паспортные данные, Общая сумма долга, Остаток долга и т.д.). [Более подробно в excel_parser](excel_parser.py) в переменной `standard_columns`.
