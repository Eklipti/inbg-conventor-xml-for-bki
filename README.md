# Конвертер EFKI

Утилита для обработки и конвертации данных о кредитных субъектах и событиях из Excel-файлов в 
специализированные XML-форматы для различных Бюро кредитных историй (ОКБ, Скоринг, КБРС, НБКИ). 
Поддерживает работу через графический (GUI) и консольный (CLI) интерфейсы.
Проект был создан для ПКО, поэтому может не подойти другим организациям; может являться для лишь примером.
Выгрузка Excel является самописной и не имеет какого-либо стандарта, 
в своём проекте вы можете изменить код для [парсинга](excel_parser.py) или сделать нужную версию файла. 

## Стек технологий

## Как запускать
Главной точкой входа в приложение является файл `main.py`. Запуск маршрутизируется автоматически в зависимости от переданных аргументов.

### Графический интерфейс (GUI)
Запустите скрипт без аргументов командной строки:
```bash
python main.py
```

### Командная строка (CLI)
Для запуска консольной версии необходимо передать минимум один обязательный аргумент — путь к входному Excel-файлу (`-i`):
```bash
python main.py -i <путь_к_excel_файлу>
```

**Дополнительные параметры CLI:**
* `-j`, `--json`: Путь к файлу конфигурации JSON (по умолчанию `config.json`).
* `-o`, `--output`: Директория для сохранения итоговых XML-файлов (по умолчанию текущая папка `.`).
* `--bki`: Список БКИ для генерации (значения: `okb`, `scoring`, `kbrs`, `nbki`). Указание флага без значений запустит процесс без сохранения файлов.
* `-l`, `--log-level`: Уровень детализации логов (доступны `TRACE`, `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`, по умолчанию `INFO`).
* `-d`, `--debug`: Запуск в режиме отладки (используется фиксированный номер запуска `1111`, конфигурационный файл не обновляется).

## Требования к входному Excel-файлу

1. **Лист данных**: Информация должна находиться на листе с названием `Активные`.
2. **Шапка таблицы**: Вторая строка листа должна содержать заголовки.
3. **Ключевой столбец**: Обязательно наличие столбца с заголовком `# в33` (используется как ID записи).
4. **Колонки**: Требуется наличие стандартных столбцов (Фамилия, Имя, Паспортные данные, Общая сумма долга, Остаток долга и т.д.). 
[Более подробно в excel_parser](excel_parser.py) в переменной `standard_columns`.
