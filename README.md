# Конвертер EFKI

Утилита для обработки и конвертации данных о кредитных субъектах и событиях из Excel-файлов в 
специализированные XML-форматы для различных Бюро кредитных историй (ОКБ, Скоринг, КБРС, НБКИ). 
Поддерживает работу через графический (GUI) и консольный (CLI) интерфейсы.
Проект был создан для ПКО, поэтому может не подойти другим организациям; может являться для лишь примером.
Выгрузка Excel является самописной и не имеет какого-либо стандарта, 
в своём проекте вы можете изменить код для [парсинга](app/excel_parser.py) или сделать нужную версию файла.

## Как запускать
Главной точкой входа в приложение является файл `main.py`. Запуск маршрутизируется автоматически в зависимости от переданных аргументов.

### Графический интерфейс (GUI)
Запустите скрипт без аргументов командной строки:
```bash
python main.py
```

### Командная строка (CLI)
Для запуска консольной версии необходимо передать минимум один обязательный аргумент — путь к входному Excel-файлу (`-i`):
```bash
python main.py -i <путь_к_excel_файлу>
```

**Дополнительные параметры CLI:**
* `-j`, `--json`: Путь к файлу конфигурации JSON (по умолчанию `config.json`).
* `-o`, `--output`: Директория для сохранения итоговых XML-файлов (по умолчанию текущая папка `.`).
* `--bki`: Список БКИ для генерации (значения: `okb`, `scoring`, `kbrs`, `nbki`). Указание флага без значений запустит процесс без сохранения файлов.
* `-l`, `--log-level`: Уровень детализации логов (доступны `TRACE`, `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`, по умолчанию `INFO`).
* `-d`, `--debug`: Запуск в режиме отладки (используется фиксированный номер запуска `1111`, конфигурационный файл не обновляется).

## Требования к входному Excel-файлу

1. **Лист данных**: Информация должна находиться на листе с названием `Активные`.
2. **Шапка таблицы**: Вторая строка листа должна содержать заголовки.
3. **Ключевой столбец**: Обязательно наличие столбца с заголовком `# в33` (используется как ID записи).
4. **Колонки**: Требуется наличие стандартных столбцов (Фамилия, Имя, Паспортные данные, Общая сумма долга, Остаток долга и т.д.). 
[Более подробно в excel_parser](app/excel_parser.py) в переменной `standard_columns`.

## Возможности программы

**Обработка и нормализация данных**
* Проверка существования Excel-файла и наличия обязательного листа "Активные" (`validate_excel`), 
а также валидация структуры конфигурационного JSON-словаря на присутствие обязательных реквизитов и счетчика запусков (`validate_config`).
* Преобразование устаревших файлов формата `.xls` в файлы `.xlsx` (`convert_xls_to_xlsx`).
* Извлечение данных из файла-донора, агрегация сумм платежей по ключу и пересчет остатка долга в основном файле, 
включая установку статусов и программную обработку перевозврата (`process_excel_returns`).
* Очистка строк с ФИО от заглушек, маркеров отсутствия данных и неразрывных пробелов (`clean_fio`), 
а также нормализация строковых полей документов с удалением спецсимволов и переводом в верхний регистр (`clean_issuer`).

**Генерация XML для БКИ**
* Формирование базовых XML-тегов кредитного события и вызов специфичных функций-помощников для добавления подблоков 
в зависимости от типа: 2.3 (изменение), 2.5 (завершение договора) и 2.11.2 (добавление) (`build_event`, `build_suffix_*`).
* Вычисление количества дней просрочки между датой начала просрочки и датой формирования документа 
с возвратом форматированного строкового значения (`calculate_days_difference`).
* Приведение числовых значений сумм к строковому формату с двумя знаками после запятой, 
заменой разделителей и автоматической обработкой пустых значений (`format_sum_to_str`).

**Системные функции**
* Сохранение инкрементированного счетчика запусков (`run_counter`) в целевой конфигурационный JSON-файл 
после успешной генерации всех XML-деревьев (`save_config`).
* Глобальная настройка уровней логирования приложения (`setup_app_logging`).
